# 规范切图工作台本地版

本地版不需要网站备案，也不依赖 Netlify、Render 或其他云端工作台地址。图片只在当前电脑处理，输出直接写回商品文件夹。

## macOS

1. 安装 Python 3.9、3.10、3.11 或 3.12：<https://www.python.org/downloads/macos/>。
2. 解压 `staccato-crop-workbench-macos-local-v2.0.zip`。
3. 双击“启动规范切图工作台.command”。
4. 首次运行会联网安装图像处理组件，通常需要 2–8 分钟；以后启动无需重复安装。
5. 如果 macOS 阻止打开，右键该文件，选择“打开”，再确认一次。
6. 浏览器会自动打开 `http://127.0.0.1:8765`。保留启动窗口，关闭窗口即停止工具。

## Windows 10/11

1. 安装 64 位 Python 3.9、3.10、3.11 或 3.12：<https://www.python.org/downloads/windows/>。安装时勾选 **Add Python to PATH**。
2. 解压 `staccato-crop-workbench-windows-local-v2.0.zip`，不要直接在压缩包内运行。
3. 双击“启动规范切图工作台.bat”。
4. 首次运行会联网安装图像处理组件，通常需要 2–8 分钟；以后启动无需重复安装。
5. 浏览器会自动打开 `http://127.0.0.1:8765`。
6. 需要停止后台服务时，双击“停止规范切图工作台.bat”。

## 使用流程

1. 点击“选择文件夹”，选择商品根目录。
2. 系统按直接子文件夹识别商品，自动识别静物、腿模和全身图。
3. 检查主体框和编号；必要时直接在画布拖动、滚轮缩放或人工修改类型。
4. 选择“无AI留白”时完全不需要 API Key。
5. 选择“AI扩图”时，在右上角齿轮中配置服务、模型和 API Key。
6. 点击“一键导出全部”，图片直接写回对应商品文件夹。

## AI 与隐私

- 静物、腿模、全身分类和普通切图在本机运行。
- 只有启用 AI 扩图且画布确实需要补全时，才向所选 AI 服务发送该张图片。
- macOS 的 API Key 保存到系统钥匙串。
- Windows 的 API Key 保存到当前用户的 `%APPDATA%\StaccatoCropWorkbench`，其他 Windows 用户不可通过工具界面读取。
- AI 失败时仍导出当前主体位置的未补图版本，并显示具体原因。

## 常见问题

- **首次安装失败**：确认网络可以访问 Python 软件源，然后重新双击启动文件。
- **端口被占用**：先关闭旧的启动窗口；Windows 可双击停止文件，然后重启。
- **没有弹出文件夹选择器**：检查系统是否把窗口放在浏览器后方。
- **AI 无法使用**：本机 ChatGPT/Codex 订阅不等于 API 额度，需要配置对应服务的独立 API Key。
- **图片识别不确定**：在右侧手动改为静物、腿模或全身，编号会自动重新分配。
